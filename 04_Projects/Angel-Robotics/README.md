# Angel Robotics | 기업분석 프로젝트

## 프로젝트 개요
엔젤로보틱스의 웨어러블 로봇 사업과 재활·보행 보조 로봇 제품군을 조사하고, 공개된 기업 자료를 바탕으로 분석한 프로젝트입니다.

## 주요 내용
- 기업 및 사업 영역 소개
- 웨어러블 로봇 제품군: angel MEDI, angel SUIT, angel GEAR
- 재무 데이터 및 주요 지표 분석
- 경쟁 기업 비교
- 재활·보행 보조 기술의 산업적 의미

## 프로젝트 자료
세부 분석과 수치는 최종 포트폴리오 PDF 및 별도 기업분석 자료를 기준으로 확인합니다.
